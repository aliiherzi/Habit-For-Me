# Habit For Me

A personal habit tracker for building good habits and keeping them.

> Status: **planning**. No code yet.

## Goal

Make it easy to:
- Add the habits you want to build (e.g. "drink water", "read 20 minutes", "exercise")
- Check them off each day
- See streaks and progress over time

## Planned features (first version)

- [ ] Add, edit and delete habits
- [ ] Mark a habit as done for today
- [ ] Show the current streak for each habit
- [ ] Simple weekly/monthly progress view
- [ ] Save data so it is still there after closing the app

## Ideas for later

- Reminders/notifications
- Charts and statistics
- Mobile-friendly design / install as an app
- User accounts and sync across devices
