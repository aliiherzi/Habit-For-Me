# How to use the $100 Claude credit

## 1. Find out what kind of credit it is

- **Claude API credit** (console.anthropic.com → Billing): pays for API calls
  made by apps and scripts.
- **Claude.ai / Claude Code usage credit** (claude.ai → Settings →
  Billing/Usage): pays for usage beyond your plan's normal limits.

Check for an **expiry date**. Promo credits often expire, so use the credit before then.

## 2. If it's Claude Code / claude.ai usage

Good uses:
- **Build something real**: a website, an app (like this one), an automation script
- **Learn while building**: ask Claude to explain code as it writes it
- **Clean up existing work**: refactors, bug fixes, tests, documentation
- **Documents and research**: reports, decks, spreadsheets, résumés

To make it last:
- Give **clear, specific requests**. Vague prompts lead to back-and-forth.
- Start a **new session for each new task**. Long conversations cost more per message.
- Skip max-effort settings and many parallel agents unless they are really needed.

## 3. If it's API credit

- Use it to build your own app (chatbot, summarizer, data extractor, bot).
- Use **cheaper, faster models** (like Haiku) for simple tasks.
- Use **prompt caching** and **batch processing** to cut costs.
- Set a **spending limit** in the console.
